# Bangkok Flood Intelligence (ระบบวิเคราะห์มวลน้ำและประเมินความเสี่ยงน้ำท่วม กทม.)

เว็บแอปพลิเคชันระบบเฝ้าระวังและวิเคราะห์มวลน้ำตามลำน้ำเจ้าพระยาก่อนเข้าสู่กรุงเทพมหานคร พร้อมคำนวณความเสี่ยงน้ำท่วมด้วย **สมการ 3 น้ำ (น้ำเหนือ + น้ำทะเลหนุน + น้ำฝนสะสม)** เชื่อมต่อข้อมูลโทรมาตรสดแบบเรียลไทม์จากสถาบันสารสนเทศทรัพยากรน้ำ (องค์การมหาชน) - สสน. / Thaiwater

---

## ฟังก์ชันเด่น (Key Features)

1. **โหมดดูอย่างง่ายสำหรับมือถือ (Mobile Simple View)**
   - ออกแบบมาให้ดูง่าย กระชับ ทราบคำตอบทันทีว่า **"กทม. จะท่วมหรือไม่?"**
   - มาตรวัดระยะปลอดภัยเทียบแนวคันกั้นน้ำ กทม. (2.50 ม. รทก.)
   - 3 ตัวเลขสำคัญ: น้ำเหนือ (บางไทร C.29A), น้ำทะเลหนุน (ม. รทก.), และฝนตกสะสม กทม. (มม.)
   - การ์ดนับถอยหลังเวลาที่มวลน้ำจะเดินทางมาถึง กทม. (ETA)
   - รายชื่อชุมชนนอกคันกั้นน้ำที่ต้องเฝ้าระวัง พร้อมปุ่มโทรสายด่วน 1555 (กทม.) และ 1460 (กรมชลประทาน)

2. **โหมดวิเคราะห์ละเอียด (Pro Analyst View)**
   - **แผนที่เส้นทางน้ำเจ้าพระยา (Interactive Hydrological Map)** แสดงหมุดสถานีโทรมาตรแบบเรืองแสงตามระดับสถานะ (เขียว/เหลือง/แดง)
   - **แบบจำลองสถานการณ์จำลอง (What-If Flood Scenario Sandbox)** ให้ผู้ใช้งานปรับเลื่อน Sliders ทดลองปรับอัตราการระบายเขื่อนเจ้าพระยา, ปริมาณน้ำผ่านบางไทร, น้ำหนุน, และน้ำฝน เพื่อดูผลกระทบต่อระดับน้ำ กทม. ทันที
   - ปุ่ม Preset เหตุการณ์เปรียบเทียบในอดีต: มหาอุทกภัยปี 2554, เฝ้าระวังปี 2565, ข้อมูลสดปัจจุบัน, ฤดูแล้งปกติ
   - ตารางโทรมาตรตรวจวัดน้ำ 10 สถานียุทธศาสตร์ (C.2, C.13, C.3, C.7A, C.35, S.26, C.29A, CPY014, C.12, CPY015)
   - สถานการณ์ 4 เขื่อนหลักลุ่มน้ำเจ้าพระยาตอนบน (ภูมิพล, สิริกิติ์, ป่าสักชลสิทธิ์, แควน้อยบำรุงแดน)

## การติดตั้งและการเริ่มใช้งาน (Getting Started)

### ความต้องการของระบบ
- Node.js v18 ขึ้นไป
- npm

### ขั้นตอนการรัน
```bash
# ติดตั้ง dependencies
npm install

# รันเซิร์ฟเวอร์
npm start
```

เปิดเว็บเบราว์เซอร์ไปที่: `http://localhost:4321`

---

## สถาปัตยกรรมระบบ (Architecture)
- **Backend:** Node.js, Express.js (API Caching & Hydrological Risk Computation Engine)
- **Frontend:** Vanilla HTML5, CSS3 (Dark Cyber Glassmorphism), Vanilla JavaScript
- **Libraries:** Leaflet.js (แผนที่ลุ่มน้ำบน Esri World Dark Canvas), Font Awesome 6
- **Data Source:** สถาบันสารสนเทศทรัพยากรน้ำ (สสน.), กรมชลประทาน, กรมอุทกศาสตร์ กองทัพเรือ
